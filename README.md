# NDI setup notes

This repository contains setup guidance only. It does not include the NDI SDK or Runtime.

## Get NDI

1. Visit the [official NDI website](https://ndi.video/) and download the SDK and/or Runtime for your platform.
2. Install the Runtime on each machine that needs to send or receive NDI streams.
3. For development, install the SDK and follow its included documentation and examples. Configure your project to use the SDK files for the correct operating system and architecture.
4. Use the NDI tools provided with the Runtime to check that your devices and sources are available on the network.
